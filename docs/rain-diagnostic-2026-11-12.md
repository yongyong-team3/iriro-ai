# 2026-11-12 강수 수집 진단

검사 시각: 22:09~22:10 KST. 서비스 키는 요청 로그에서 제외했다.

## 실제 요청과 원시 응답

- 강수 수집 요청: `GET https://www.safetydata.go.kr/V2/api/DSSP-IF-00006?serviceKey=<redacted>&returnType=json&pageNo=39597&numOfRows=1000`. 수집 코드는 먼저 `pageNo=1`로 `totalCount`를 읽고 마지막 페이지부터 조회한다. 강수 요청에는 날짜·시각·관측소 파라미터가 없다.
- 응답: HTTP 200, `header.resultCode="00"`, `header.resultMsg="NORMAL SERVICE"`, `totalCount=39596223`. 마지막 페이지(39597)의 223행 중 관측 시각 최댓값은 `202611100810`이고, `10164050`은 없다.
- 직전 페이지(39596)의 원시 행: `{"YMD_HM":"202611100410","WALE_OBSVTR_CD":"10164050","THEX_DATA":0}`. 이 페이지의 관측 시각 최댓값도 `202611100810`이다.
- 따라서 최근 3시간(2026-11-12 19:09~22:09 KST)의 대상 관측값은 마지막 페이지에 없다. 인증·권한 오류라면 예상되는 실패 응답과 달리, 이 요청은 성공 코드와 데이터 행을 반환했다.

## 시각 검증

- 배포 컨테이너의 `datetime.now()` 기준 시각은 UTC였다. 21:50 KST에 `/health.data_now`와 `last_water_at`은 12:50으로 표시됐다.
- 직접 조회한 월촌교 수위 원시 행은 `YMD_HM=202611122130`, `MAAS_OBNT_DT=2026/11/12 21:49:44`였다. 22:10 KST 조회 시 UTC 컷오프 13:10 이후의 수위 행이 50건 있었다. 코드의 UTC 기반 `end` 필터가 이 행들을 제외했다.
- 강수는 요청에 시각 파라미터가 없고 원시 응답 자체가 11월 10일에서 멈췄다. 9시간 보정만으로는 현재 강수값을 얻을 수 없다.

## 처리

- 수집기의 시간 창과 `/health`의 최신성 비교만 `Asia/Seoul` 기준으로 수정했다.
- 과거에 `THEX_DATA=0`인 행이 실제로 존재한다. 비가 없을 때 행이 생략된다고 입증되지 않았으므로 결측 강수는 0으로 채우지 않는다. `last_rain_at=null`, `forecast_1h=null`이 계속되면 플랫폼 원천 자료 지연을 확인해야 한다.
- 수정본을 `TZ=UTC`에서 실제 API로 검증했다. 호스트 시각 13:15, `last_refresh=22:15`, `last_water_at=21:30`, `last_rain_at=null`, `data_error=null`이었다. `/live/status`는 21:30 수위 0.54m와 강수 결측을 반환했다.
- `/replay/predict?time=2024-07-18T10:00` 결과는 변경 전과 동일하게 현재 4.81m, 예측 4.64m, 실제 4.82m였다.
